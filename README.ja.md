*Nunsseop*(눈썹)は韓国語で*眉*、画面の上にある小さなアーチのことです。無料のオープンソースで、アカウントも、サブスクリプションも、トラッキングもありません。

## 30秒でインストール

```sh
brew install --cask namekun/tap/nunsseop
```

[Homebrew](https://brew.sh) が必要です。Homebrew が隔離フラグを外すので、すぐに開けます。アップデートは `brew update && brew upgrade --cask nunsseop` で行えます。新しいバージョンが出ると、設定 › 一般 › アップデートでそのコマンドをクリップボードにコピーできます。

macOS 14 Sonoma 以降が必要です。Apple シリコンと Intel の両方に対応し、ノッチのない画面でも動作します。

## 最初の1分

1. **ノッチにポインタを重ねます。** ノッチが開きます。ポインタを離すと、自然に閉じます。
2. ミュージック、Spotify、YouTube Music、またはブラウザで**何か再生してみてください。** ノッチが曲を検出し、閉じた状態でも小さなアートワークとビジュアライザが表示されます。
3. **ノッチを右クリック → 設定**で、タブとその並び順、表示したいポップアップ、サイズを選べます。

Dock にアイコンは出ません。Nunsseop はノッチの中にいます。

## できること

**🎵 音楽**
- **どのアプリの再生中情報も表示。** ミュージック、Spotify、YouTube Music のほか、Safari、Chrome、Arc、Dia、Aside などのブラウザにも対応します。アートワーク、コントロール、ドラッグできる再生バーを備えています。
- **同期歌詞**を [LRCLIB](https://lrclib.net) から取得し、タイトルの下、または作業中はノッチの下に表示します。
- **スニークピーク。** 曲が切り替わると、タイトルが一瞬だけ滑り出します。
- **ポッドキャストや長い動画**では、プレーヤーが対応していれば、15 秒スキップと再生速度ボタン(1× から 2×)が使えます。

**🗂️ 作業を進める**
- **シェルフ。** ファイルをノッチにドラッグして、あとで取り出せます。画像、PDF、動画のプレビューにも対応します。スクリーンショットや完了したダウンロードを自動で置くこともできます。ファイルをドラッグしながらポインタを振ると、どこにいても、すぐ横に小さなドロップ先が現れます。
- **カレンダーとリマインダー。** 今日の日付を大きな数字で表示し、予定のある日には点が付いた 1 週間、今日の予定、チェックできるリマインダーを表示します。macOS に追加したすべてのアカウント(Google、iCloud、Exchange など)に対応し、表示するカレンダーも選べます。
- **次の予定。** 時刻のある予定が始まる 5 分前に、ノッチにタイトルと開始までの時間が表示されます。Zoom、Google Meet、Teams、Webex、FaceTime、Whereby、Chime のリンクがある予定は、ホームに緑色の「参加」ボタンが出て、通知をクリックするとそのままミーティングに参加できます。
- **Spotlight や Raycast の代わりになる検索。** アプリ(「アプリケーション」の外にあるものも)、ファイル、システムコマンドと設定、クリップボード履歴、絵文字(`:` から入力)、`12*(3+4)` のような計算に対応し、よく開くものが上位に並びます。頭文字でも検索でき、`vsc` と入力すれば Visual Studio Code が見つかります。矢印キーで選び、Return キーで開きます。
- **自分だけのショートカット。** 初期設定は <kbd>⇧⌘Space</kbd> で、設定から好きな組み合わせを記録できます。macOS や他のアプリがすでに使っている場合は、Nunsseop が知らせてくれます。
- **タイマー、クリップボード履歴、メモ、絵文字ピッカー。** クリップボード履歴はメモリ上にだけ保持され、パスワードマネージャが機密としてマークしたものは記録しません。コピーしたリンクからは、`utm_` や `fbclid` などのトラッキングパラメータが取り除かれます。

**💻 Mac の状態**
- **システム HUD。** 音量、明るさ(DDC 対応の外部ディスプレイを含む)、キーボードバックライト、充電、Caps Lock、AirPods のバッテリーがノッチに表示されます。音量キーと明るさキーを横取りして、システム標準の HUD を出さないようにすることもできます。
- **システム統計とバッテリー。** CPU、メモリ、ディスク、ネットワークに加え、マウス、キーボード、トラックパッドの状態も表示し、残量が少なくなると警告します。
- **カメラとマイクのインジケータ。** いずれかのアプリが使っている間、ノッチに点が表示されます。
- **ツール。** オーディオ出力の切り替え、アプリごとの音量調整(実験的、macOS 14.2 以降)、マイクのミュート、Mac をスリープさせない、画面収録、ドライブの取り出し、画面上のどこからでも色を拾うカラーピッカー、テキスト取得(画面のどの部分からでもテキストをコピーできます)。
- **天気、ダウンロード、ミラー、Dock のアプリ**も、ポインタを重ねるだけ。

**📞 閉じている間も**
- **通話。** Zoom、FaceTime、Teams、Slack、Discord、WhatsApp、Google Meet で通話中は、閉じたノッチにアプリ名と通話時間が表示されます。どのアプリがマイクを使っているかで判定するので、追加の権限は要りません。Zoom、FaceTime、Meet なら、通話画面に切り替えなくても、ノッチからマイクのミュートやカメラのオフができます。
- **左右に表示する内容を選べます。** 何も再生していないときは、Claude Code や Codex の残り使用量、作業中のエージェント、バッテリー、天気、日付を表示できます。
- **音楽とタイマー。** 音楽の再生中は小さなアートワークとビジュアライザ、タイマーの動作中は残り時間を表示します。
- **ダウンロード。** Safari や Chrome のダウンロードの進み具合を、Finder がファイルに表示するのと同じ進捗から、パーセントで表示します。ポーリングはしていません。

**🤖 開発者向け**
- **AI 使用量。** Claude と Codex の上限とリセット時刻、直近 5 時間と 7 日間のトークン使用量を、Claude Code、Codex、gjc、omo、OpenCode をまとめて集計して表示します。これらのツールがすでに Mac に保存しているファイルを読むだけなので、サインインは不要です。
- **Claude の上限をリアルタイム取得(オプトイン)。** AI タブで、Claude Code がキーチェーンに保存しているサインイン情報を使い、Claude の 5 時間と週の上限を約 1 時間ごとに Anthropic から取得するかどうかを一度だけ確認します。「はい」と答えるまではオフで、あとから設定 › サービスで変更できます。
- **エージェントとターミナルからの通知。** Claude Code、Codex、Gemini CLI、OpenCode のフック、Muxy・cmux・herdr 内のエージェント、tmux や WezTerm のベルがノッチに表示されます。通知をクリックすると、そのターミナル、ペイン、タブが前面に出ます([設定方法は下記](#エージェントとターミナルの通知))。
- **通知タブ。** エージェント、ターミナル、カレンダーからの直近 30 件の通知を表示し、未読にはバッジが付きます。クリックすると送信元に戻れます。初期設定ではオフ(設定 › ノッチ)で、メモリ上にだけ保持されます。
- **作業中のエージェント。** 閉じたノッチに表示される項目で、入力を待っているコーディングエージェントの数(黄色の手)、待っているものがなければ作業中の数(緑の稲妻)を示します。現時点では herdr に対応しています。

**🧩 自分好みに**
- タブとその並び順、ヘッダと閉じたノッチの表示内容、表示するポップアップを選べます。**オフにした機能は動作自体を止めます。**
- macOS 26 では、開いたノッチとカードに Liquid Glass を使い、背後がやわらかく透けて見えます。ガラスの濃さは最大 100% の真っ黒なノッチまで調整でき、ガラス表現をオフにすることもできます。
- ノッチのないディスプレイでは、閉じたノッチはメニューバーの中に眉のロゴが入った小さなバーとして表示されます(お好みでガラス調に)。使われないまま一定時間(3〜60 秒、または無効)が過ぎるとフェードアウトし、ポインタが近づくと戻ります。そこに 0.5 秒とどまると開きます。
- ディスプレイ、サイズ、ホバーの待ち時間、ログイン時の自動起動、クラムシェル(蓋を閉じた状態)でのノッチ非表示を設定できます。
- 下にスワイプで開き、上にスワイプで閉じ、ホームで横にスワイプすると曲をスキップできます。
- English、한국어、日本語、简体中文、Español、Deutsch、Français に対応し、Mac の言語設定に従います。

## FAQ

<details>
<summary><b>macOS に「Nunsseop は開けません」と表示されます。</b></summary>

アプリはまだ公証されていないため、Homebrew でインストールしてください(`brew install --cask namekun/tap/nunsseop`)。Homebrew が隔離フラグを外すので、すぐに開けます。
</details>

<details>
<summary><b>音楽を再生しても何も表示されません。</b></summary>

Nunsseop は、macOS が「再生中」として認識している内容を表示します。そのため、プレーヤーがコントロールセンターに表示される必要があります。ほとんどのアプリとブラウザは表示されます。代替手段については、[再生中情報の取得方法](#再生中情報の取得方法)をご覧ください。
</details>

<details>
<summary><b>検索で Spotlight を置き換えられますか?</b></summary>

はい。設定 → サービスを開き、ショートカットをクリックして <kbd>⌘Space</kbd> を押してください。Spotlight が使っていることを Nunsseop が知らせ、キーボードショートカットを開くので、そこで「*Spotlight 検索を表示*」のチェックを外します。検索タブを非表示にしていても、検索は開きます。
</details>

<details>
<summary><b>タブが多すぎます。</b></summary>

ノッチを右クリック → 設定 → ノッチで、不要なものをオフにしてください。オフにした機能は完全に動作を止めます。
</details>

<details>
<summary><b>お使いの Mac にノッチがありません。</b></summary>

蓋を閉じた状態の外部モニタなど、ノッチのないディスプレイでは、閉じたノッチはメニューバーの中に浮かぶ、眉のロゴが入った小さなバーになります。ポインタを重ねると眉が持ち上がり、開くとノッチが通常のサイズで画面上端に取り付きます。使われないときはフェードアウトします。オフにしたり、待ち時間を変えたりするには、設定から行えます。使用するディスプレイもそこで選べます。
</details>

<details>
<summary><b>AI 使用量に古い Claude の上限が表示されるのはなぜですか?</b></summary>

初期設定では、Claude の 5 時間と週のパーセンテージは、他のツールが書き込むキャッシュから取得されます。ターミナルで Claude Code を使っている間の [oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode) の HUD、または gjc が書き込んだものです。カードには最終更新時刻が表示されます。設定 › サービスで接続すると、Claude の上限を Claude Code のステータスラインから直接取得することもできます。それらがなくても最新の上限を表示したい場合は、AI タブまたは設定 › サービスで、Claude の上限のリアルタイム取得をオンにしてください。トークンの合計は常に最新です。
</details>

<details>
<summary><b>アップデート後、音量キーで Nunsseop の HUD が出なくなりました。</b></summary>

0.8.3 より前のバージョンは、アップデートのたびに macOS がアクセシビリティの許可を忘れてしまう署名方法でした。0.8.3 以降は許可が保持されます。古いバージョンからアップデートした場合は、システム設定 → プライバシーとセキュリティ → アクセシビリティから一度 Nunsseop を削除し、もう一度許可してください。再起動しなくても反映されます。
</details>

## エージェントとターミナルの通知

Nunsseop は `127.0.0.1:47750` で、Mac 上のツールからの通知を待ち受けます。リクエストには、`~/Library/Application Support/Nunsseop/notify-token` に保存されたシークレットトークンが必要です。

設定 → 通知を開き、Claude Code、Codex、Gemini CLI、OpenCode の横にある**接続**を押します。この Mac で使ったことのあるツールだけが一覧に表示されます。Nunsseop はそのツールの設定ファイル(`~/.claude/settings.json`、`~/.codex/config.toml`、`~/.gemini/settings.json`)を書き換えるか、`~/.config/opencode/plugins` にプラグインを追加し、元のファイルは拡張子 `.nunsseop-backup` を付けて残します。Codex は `notify` コマンドを 1 つしか使えないため、すでにあるコマンドは Nunsseop のコマンドの後に実行されます。**接続解除**で元に戻せます。その後に開始したセッションの通知が、ノッチに送られます。

Claude Code を手動で設定するには、**Claude Code フックのコマンドをコピー**を押して、`~/.claude/settings.json` に追加します。

```json
{
  "hooks": {
    "Notification": [
      { "hooks": [{ "type": "command", "command": "<paste the copied command here>" }] }
    ]
  }
}
```

ターミナルやエージェントアプリには、フックは不要です。

- **Muxy** と **cmux:** アプリ自身の通知を読み取ります。アプリが前面にあるときは表示しません。
- **herdr:** すべてのセッションで、終了したエージェントや入力を待っているエージェントを、herdr のソケットから読み取ります。
- **tmux:** すべてのウインドウのベルに対応します。Nunsseop は実行中の tmux サーバーにだけフックを追加し、`tmux.conf` は変更しません。
- **WezTerm:** 設定 › 通知でコピーした行を `~/.wezterm.lua` に貼り付けると、ベルに対応します。

それぞれ、ツールがインストールされている場合に限り、設定 › 通知にトグルが表示されます(WezTerm は、設定の行をコピーするボタンになります)。すでに専用のフックで接続済みのツールは、重複して表示されません。

スクリプトからも通知を送れます。

```sh
curl -X POST http://127.0.0.1:47750/notify \
  -H "Authorization: Bearer $(cat ~/Library/Application\ Support/Nunsseop/notify-token)" \
  -d '{"title": "Build", "message": "Finished in 42 s"}'
```

## 権限

Nunsseop は、その権限を必要とする機能を初めて使うときにだけ、許可を求めます。

| 機能 | 権限 | 許可を求めるタイミング |
| --- | --- | --- |
| カレンダー | カレンダー | ホームタブで*アクセスを許可*を押したとき |
| リマインダー | リマインダー | ホームタブで*リマインダーを許可*を押したとき |
| ミラー | カメラ | ミラータブで*カメラを許可*を押したとき |
| 画面収録、他のアプリのウインドウからのテキストコピー | 画面収録 | 初めて録画またはテキストの取得を始めたとき |
| 音声付きの録画 | マイク | 初めてマイク音声をオンにして録画したとき |
| 音量、明るさ、キーボードバックライトキーの横取り | アクセシビリティ | 設定でそのオプションをオンにしたとき |
| ミュージック、Spotify、ブラウザの再生中情報の代替取得 | オートメーション | MediaRemote ヘルパーが使えない場合のみ |
| ブラウザでの Google Meet、Zoom、Teams の通話表示 | オートメーション(そのブラウザ) | ブラウザが初めてマイクを使ったとき |
| ログイン時に開く | ログイン項目 | 設定でオンにしたとき |

## プライバシー

Nunsseop は個人データを収集も送信もしません。オンラインに接続するのは、次の場合だけです。

- `api.github.com` で、新しいリリースがないかを 1 日 1 回確認します(オフにできます)。
- `lrclib.net` で、同期歌詞を検索します(オフにできます)。
- 入力した都市の天気を `open-meteo.com` から取得します(都市を入力するまではオフ)。Open-Meteo で見つからない場合は、都市の位置を Apple のジオコーダに問い合わせます。
- MediaRemote ヘルパーが使えない場合に限り、既知の音楽サービスから HTTPS でアートワークをダウンロードします。
- Claude の上限のリアルタイム取得をオンにした場合に限り、キーチェーンにある Claude Code のサインイン情報を使って、約 1 時間ごとに `api.anthropic.com` へ上限を問い合わせます。

それ以外はすべて Mac の中にとどまります。通知サーバーは、この Mac からの接続しか受け付けません。AI 使用量は、Claude の上限のリアルタイム取得をオンにしない限り、ローカルのファイルから読み取ります。通知タブの通知は、メモリ上にだけ保持されます。録画はスクリーンショットの保存先に保存されます。カメラのプレビューはミラータブを開いている間だけ動作し、録画されることはありません。クリップボード履歴は、Nunsseop を終了すると消去されます。

## 再生中情報の取得方法

macOS 15.4 以降、非公開の MediaRemote フレームワークは Apple が署名したプロセスにしか応答しません。そこで Nunsseop は小さなヘルパーライブラリ(`Sources/NowPlayingHelper`)を同梱し、システムの `/usr/bin/perl` の中で実行して、再生中の状態を読み取り、再生、一時停止、スキップ、シークのコマンドを送り、JSON の行をアプリにストリームで返しています。

これは非公開 API に依存しているため、今後の macOS アップデートで動かなくなる可能性があります。その場合、Nunsseop はミュージックと Spotify には AppleScript を、ブラウザにはメディアタブの読み取りを代替手段として使います。この代替手段には、各ブラウザで「*Apple Events からの JavaScript を許可*」をオンにする必要があります。Dia にはそのメニュー項目がないため、Nunsseop が `--enable-applescript-javascript` を付けた再起動を提案します。

## ソースからビルド

```sh
git clone https://github.com/namekun/Nunsseop.git
cd Nunsseop
./scripts/bundle.sh release      # build/Nunsseop.app
./scripts/make-dmg.sh            # build/Nunsseop-<version>.dmg
```

Swift 5.10 以降を含む Xcode コマンドラインツールが必要です。`scripts/bundle.sh` は Swift パッケージをビルドし、アドホック署名のアプリバンドルにまとめます。
